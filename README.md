# منصة زاد للدعم المدرسي — نسخة الواجهة الأولى

## ما الموجود؟
- واجهة عربية RTL متجاوبة مع الهاتف والحاسوب.
- صفحات أقسام الدروس والمواد ومكتبة الموارد.
- نوافذ توضيحية تجريبية لأزرار الدخول والمقررات.
- ملف `supabase_schema.sql` كبداية لهيكل قاعدة البيانات.

## التشغيل في VS Code
1. فك ضغط الملف ZIP في مجلد واضح.
2. افتح VS Code ثم File > Open Folder واختر مجلد `zad_platform`.
3. افتح `index.html` في المتصفح. يُفضّل تثبيت إضافة Live Server من متجر إضافات VS Code.
4. بعد تثبيت Live Server، اضغط بزر الفأرة الأيمن على `index.html` ثم Open with Live Server.

لا تحتاج هذه الواجهة إلى قاعدة بيانات كي تظهر. الأزرار والحسابات حاليًا تجريبية وليست نظامًا منشورًا.

## ربط Supabase لاحقًا
1. أنشئ مشروعًا جديدًا في Supabase.
2. افتح SQL Editor ثم انسخ محتوى `supabase_schema.sql` وشغّله بعد مراجعته.
3. من Project Settings > API انسخ Project URL وpublishable/anon key.
4. لا تضع `service_role` أو أي مفتاح سري في ملفات HTML أو JavaScript العامة.
5. في مرحلة الربط سنضيف مكتبة Supabase للواجهة وننشئ التسجيل والدخول واستعراض الدروس. يجب اختبار سياسات RLS جيدًا قبل استخدام بيانات حقيقية.

## تنبيهات قبل النشر
- لا توجد حاليًا مصادقة حقيقية أو دفع إلكتروني أو إشعارات فعلية.
- لا ترفع وثائق خاصة إلى مخزن عام. أنشئ Storage bucket خاصًا وسياسات وصول مناسبة.
- الدفع الإلكتروني يحتاج مزود دفع معتمدًا في بلدك، والتحقق من الدفع يجب أن يتم على الخادم لا في المتصفح.
- لا تجعل المستخدم يختار دور `admin` من نموذج التسجيل. تعيين الإدارة يتم يدويًا من إجراء آمن.
- لا تستخدم بيانات تلاميذ حقيقية قبل ضبط الصلاحيات والخصوصية والنسخ الاحتياطي.
